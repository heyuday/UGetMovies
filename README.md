# 🎬 Movie Watchlist Web App

A full-stack **MERN** application that allows users to explore, save, and manage their favorite movies. Features secure authentication, personalized watchlists, and a modern, responsive frontend.

## 🚀 Features

- **User Authentication** — Secure login/signup with JWT and Passport.js  
- **Personal Watchlists** — Add or remove movies dynamically  
- **RESTful API** — Modular backend with Express.js and MongoDB  
- **Responsive UI** — Built with React and reusable components  
- **Environment-Based Config** — `.env` used for keys, DB URIs, and JWT secrets  
- **Clean Folder Structure** — Separation of backend and frontend logic for scalability  

---

## 🧩 Tech Stack

| Layer | Technologies |
|--------|---------------|
| **Frontend** | React, CSS |
| **Backend** | Node.js, Express.js |
| **Database** | MongoDB (via Mongoose) |
| **Auth** | JWT, Passport.js |
| **API** | REST |
| **Deployment** | Render / Vercel / MongoDB Atlas |
